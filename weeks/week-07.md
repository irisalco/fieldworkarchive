#### 作品完整論述

「維某年某月某日，造園者致告於隙地之莠草曰： 凡花園之設，必有常度；良莠之辨，本屬殊途。爾等牛筋、土香、酢漿之屬，不辨疆界，潛滋暗長，僭越庭階，亂我園林之序。今以樹脂錮其身，絕其根脈，懸於輪盤，勒令歸檔。限日剔除，不得有誤！」

雜草從非天生，只是長錯位置罷了。作品以台灣本土強勢雜草為核心媒材，探討當代社會中良莠不齊的價值判定，以及個體面臨非自願錯位時的生存焦慮。將雜草面臨死亡的命運，投射為邊緣群體在體制篩選下的脆弱處境，喚起一種物傷其類、兔死狐悲的共感。

《祭莠文》是一場披著權力外衣的自我悼念。觀者在展場中看著機器機械化的翻閱、篩選這些被定罪為「莠」的生命，初看似是掌握生殺大權的園丁；但在機械無止盡的輪轉與逼問下，卻將意識到自身亦處於龐大社會系統的檢視之中。我們努力偽裝成結穗的「良」，卻始終處於隨時可能被判定為「莠」而遭連根拔起的恐懼。

作品透過樹脂包埋標本技術，將具有強悍在地野性、姿態各異的本土雜草，壓製成尺寸、厚度完全一致的檔案薄片。將有機生命標本化的過程，隱喻了僵化體制如何透過單一規格，粗暴地剝奪個體的異質性。不論是葉片還是深埋土中的根，皆無所遁形地被凝結於透明的凝視之中。

被規格化的雜草標本，掛載於老式旋轉名片架上。這台象徵著舊時代官僚建檔與記憶汰除的機器，透過觀者的介入，成為一台冷酷的分類儀器。這種物理上的摩擦，具象化了那些無法被體制完美收編的邊緣生命，其徒勞卻真實的抵抗。

### Richard Serra 動詞

- **to laminate（層壓 / 壓合）**
- **to encircle（環繞）/ to rotate（旋轉）**
- **of entropy（關於熵 / 混亂度）：雜草是自發、無序、反抵抗體制的存在**

**花園：熵減（秩序增加 混亂度下降）**

**園丁 + 工具 + 生物圈+雜草本身：熵增（總混亂度增加）**

- **of tension（關於張力） ：觀者（潛在的審判者）與被展出物（被審判者）之間**

context 脈絡

intra-action  **事物與關係是在彼此作用的過程中才共同建構與誕生**，沒有預先存在的獨立邊界。(雜草是在人眼裡才是雜草 )

Touché  接觸與傷害 (比較像是發生在我跟作品之間 觀眾看到的是結果)

temporality (時間性)

Representational challenges（再現的難題）

# 作品二

新嘗試：摒棄作品中太過濃厚的死亡意象 轉而以誕生本身作為主題

生死其實是一體兩面的

蛋殼磨粉作沙漏 時間推進

**永劫回歸**（德語：Ewige Wiederkunft，又譯為**永恆輪迴**、**永恆重現**）是一個哲學概念，意思是：**假定宇宙與其中的一切事物，會在無限的時間中以完全相同的方式、無數次地重複發生。**

**時間是圓形而非直線**：你所經歷過的過去、當下的每一個念頭、吹過的風、感受到的快樂或痛苦，都不是只發生一次就永遠消失，而是在漫長的時空中不斷循環重演。

透過觀眾介入，翻轉沙漏，即是一次循環。
